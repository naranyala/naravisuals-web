## 🚀 How to Update Content

### Quick Updates (FAQ, Social Links, Categories)
1. Edit `src/app/shared/services/app-content.service.ts`
2. Find the relevant section
3. Update the content
4. Save - changes appear immediately in dev mode

### Adding New Articles
1. Create new `.md` file in `/docs/` folder
2. Use format: `XX-article-title.md`
3. Write content with markdown
4. Build process auto-bundles it
5. Article appears in blog automatically

### Modifying Existing Articles
1. Open the `.md` file in `/docs/`
2. Edit the content
3. Save and rebuild (or auto-reload in dev)
