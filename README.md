# Rigorstarter Webpage

Rigorstarter Webpage is a lightweight, high-performance documentation site built using Rust and the Leptos framework. It leverages client-side rendering (CSR) and compile-time embedding of markdown content to provide a seamless and fast user experience.

## Features

- Automatic Page Generation: New documentation pages are automatically created by adding Markdown files to the docs directory.
- Compile-Time Embedding: Content is embedded into the binary at compile time, eliminating the need for runtime API calls to fetch documentation.
- Client-Side Routing: Fast, instantaneous navigation between pages using leptos_router.
- Markdown Support: Renders Markdown content into HTML using pulldown-cmark.

## Tech Stack

- Rust
- Leptos (CSR)
- pulldown-cmark
- Trunk (Build tool)

## Project Structure

- docs/: Contains Markdown files (.md). Each file becomes a page on the website.
- src/:
  - main.rs: Core application logic, routing, and UI components.
  - docs_data.rs: Automatically generated by build.rs; maps paths to markdown content.
- styles/: Contains the CSS for the site's appearance.
- build.rs: Build script that scans the docs folder and generates docs_data.rs.
- index.html: The entry point for the WebAssembly application.

## Getting Started

### Prerequisites

To build and run this project, you need:
- Rust (stable)
- Trunk: Install via `cargo install trunk`
- WASM target: `rustup target add wasm32-unknown-unknown`

### Running Locally

1. Clone the repository.
2. Navigate to the project root.
3. Run the following command to start a development server:
   ```bash
   trunk serve
   ```
4. Open your browser and navigate to `http://localhost:8080`.

### Building for Production

To create an optimized production build:
```bash
trunk build --release
```
The output will be located in the `dist/` directory.

## Adding New Documentation

Adding a new page is simple:
1. Create a new `.md` file in the `docs/` directory (e.g., `docs/my-new-page.md`).
2. Add a first-level heading (`# Page Title`) to the top of the file; this will be used as the sidebar link title.
3. Rebuild or restart the server. The `build.rs` script will automatically detect the new file and add it to the navigation sidebar and routing.
