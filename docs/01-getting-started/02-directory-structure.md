## Directory Purposes

### Plugin Registry Architecture

| Directory | Purpose |
|-----------|---------|
| `docs/` | Source Markdown documentation. File prefixes control order: `01-` = first, `02-` = second, etc. Supports nested folders for collapsible sidebar categories. Each `.md` file has YAML frontmatter (title, description, etc.) |

:::tip Adding New Documentation
To add a new document: create a `.md` file in `docs/`, use YAML frontmatter for title/description, and use numeric prefixes like `01-`, `02-` to control sidebar order.
:::

| Directory | Purpose |
|-----------|---------|
| `scripts/` | Build-time tooling. The `build-docs.mts` script scans `docs/`, processes markdown through a plugin pipeline, and generates TypeScript data files. |
| `scripts/plugins/` | Markdown processing plugin system. Three plugins: math (LaTeX), admonitions (callout blocks), mermaid (diagrams). Each implements the `MarkdownPlugin` interface with `preProcess` and `postProcess` hooks. |
| `server/` | Production deployment server. A thin wrapper around the `serve` npm package for static file serving with SPA history fallback. |
| `src/` | React application source code. All components, hooks, services, and styles. |
| `src/generated/` | **Auto-generated** by `build-docs.mts`. Contains `sidebarData`, `allDocs` array, and one `.ts` file per document. This is the "compiled" output of the markdown build pipeline. |

| Directory | Purpose |
|-----------|---------|
| `src/services/` | Dependency Injection container. Defines interfaces for browser APIs (storage, router, DOM, theme) with default implementations and mock alternatives for testing. |
| `src/hooks/` | 14 custom React hooks for theme management, scroll tracking, clipboard, keyboard shortcuts, media queries, reading time, and more. |
| `src/styles/` | Modular CSS architecture. 18 separate CSS files imported in dependency order by `index.css`. Uses CSS custom properties (variables) for theming. |
| `tests/` | Comprehensive test suite using Bun's built-in test runner with JSDOM and @testing-library/react. 15 test files covering components, services, build pipeline, and generated output. |
