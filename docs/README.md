## 📝 How to Add New Articles

1. Create a new `.md` file in this `/docs` folder
2. Use the naming convention: `XX-article-title.md`
3. The build process automatically bundles it
4. Articles appear in the blog automatically

## 🎨 Article Format

Articles support:
- **Markdown formatting** (headers, lists, bold, italic)
- **HTML elements** for custom styling
- **Mermaid diagrams** for flowcharts
- **Tables** for structured content
- **Blockquotes** for emphasis

## 📖 Reading Articles

Articles are displayed in the blog's article list component. Click any article to read the full content in the article reader.
